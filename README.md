Implementazione della Trasformata di Burrows-Wheeler (BWT) con comunicazione Client-Server TCP in Python

La trasformata di Buttows-Wheeler è una tecnica di riordinamento dei caratteri di una stringa che raggruppa simboli simili aumentando la fattorizzazione dei dati per successive fasi di compressione.

Funzionamento:

Data una stringa di lunghezza N, vengono svolte tramite ciclo for tutte le sue permutazioni spostando lultimo carattere all'iniziio o il primo alla fine per ottenere N stringhe diverse.
